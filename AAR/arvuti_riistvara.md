PC tyypi arvuti
IB projekteeris esimese PC

Esimene programm, mis toole laheb on BIOS/UEFI

"IBM compatible" - IBM yhilduv (PC eelkaijad)

Nyydseks on riistvara standardite juhtroll Microsoft, Intel, AMD, NVIDIA

tolm isoleerib soojust, kui cpu kuumeneb yle, ss taktsagedus tommatakse alla

mikrokoontroller - vaike digiarvuti, mille kmponendid on integreeritu 1 mikrokiibi sisse

SoC = System on a Chip - See on integreeritud mikrokiip, millele on kantud terve arvuti või elektroonikasüsteemi toimimiseks vajalikud komponendid ühele ainukesele ränikiibile (kristallile) <- need on mobiili, tahvel ja sylearvutites (teatud juhtudel laua- ja serveriarvutis)

Tanastes CPU-des on (operatiiv)mälu yhendatud CPU-ga ning aina enam komponente yhendatakse CPU-ga (seeprst saab kutsuda neid SoC-deks)

Arvutisysteemide klassifitseerimine

Traditsiooniliselt
- bitilisuse jargi (8,16,32,64)
- CPU arh (x86/x64, ARM/ARM64, RISC-V, Itanium (IA64), MIPS, PowerPC, Alpha, SPARC)

arvutustehteid saab CPU aind registrites olevate andmetega

ASM - inimloetav baitkood

CISC - complex instructin set computer - arendaja annab 1 universaalse keeruka kasu ja cpu ise jagab tykkideks

RISC - Reduced intruction set computer - koik kasud elementaarsed ja laiali loodud, iga tegevuse jaoks eraldi kask (UNIX philosophy)
disadvatnage - RISC programm votab malus rohkem ruumi (HOLY BLOAT)
advantage - sama ajaga suutis cpu rohkem teha (energia efektiivsem)
