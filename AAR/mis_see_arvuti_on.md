All in one arvuti - koik on monitori sees


Millest arvuti koosneb {
  CPU, GPU, laienduskaardid, andmekanjad (SSD (sata v NVME), HDD),
  optilise andmekandja seade, emaplaat, operatiivmälu (RAM), toiteplokk,
  sisend/väljund ühendused (HDMI, USB),
}

Arvuti = funkntsionaalyksus, mis teeb inimese eest keerulisi arvutusi 

Digitaalarvuti { 
  arvuti mida juhivad temas talletatud programmid ning mis on voimeline kasutama yhist maluseadet programmde taitmiseks vajalike andmete
  jaoks, jooksutab programme, mida inimene on loonud ja maaranud, teeb kasutaja maaratud toimed digitaalselt tehes aritmeetika ja loogika  
  tehteid, taidab programme, mis taitmise ajal end muudavad
}

Mikroarvuti = {
  digitaalarvuti, mille keskseade pohineb mikropriotsessoril ning sisaldab maluseadet ja sisend/valjund vahendit
}

Presonaalarvuti = mikroarvuti, mis on moeldud eeskatt yksikisikule kasutamiseks
