Vahemalu (Cache)

Paigutades programmi aktiivse osa kiiresse vahemallu, saame suurevoidu programmi tooajas

Eelmisel slaidil kirjapandud ajalise läheduse tõdemus soovitab lugeda kõik
vajaminevad käsud vahemällu
– tõenäoliselt läheb neid varsti uuesti tarvis

Eelmisel slaidil kirjapandud ruumilise läheduse tõdemus soovitab lugeda
vahemällu mitte üksikud käsud vaid ka nende naabruses asuvad käsud
– s.t loeme andmed vahemällu plokkide kaupa (block, cache line)
– tõenäoliselt läheb ka neid käske varsti tarvis

Pohimalu <-> vahemalu <-> CPU
Kui vajatakse malust andmeid ss loetkse need vahemallu
kui vajalikud andmed juba vahemalus ss loeatakse kohe sealt
Tagatakse vastavus pohimalus ja vahemalus resideeruva koopia vahel (mapping func)
Kui vahemalu on tais ss tuleb uute andmete lisandumisel mdagi valja visata (replacement algorithm)

CPU ei pea olema teadlik vahemalu olemasolust
  - tema annab ainult malust lugemise ja kirjutamise kaske
  - Vahemälu kontrollahelad selgitavad välja, kas vajalik info on juba vahemälus (tabamus)
  - või tuleb info alles vahemälusse lugeda (möödalask)
Kui andme on juba vahemalus ss pohimalust ple tarvis lugeda

Kirjutamiseks on 2 varianti
write thtough - nii vahemalu kui ka malu uuendatakse yheaegselt
write-back, copy-back - uuendtakase aind vahemalu
  - vahemalust ploki eemaldamisel uuendatakse info ka pohimalus
  - Info uuendamise vajaduse kohta kajastub muudetud lipubitis (modified, dirty bit)

Kui infot ple vahemalus
Lugemine (Read miss)
  - loetakse kogu plokk pohimalust vahemallu ning edastatakse vajalik sona CPU-le
  - loetakse info pohimalust ja edastatakse vajalik sona protsessorile kohe kui ta on olemas (load through, early restart) (veidi kiirem, aga nõuab keerukamaid juhtimisahelaid)
Kirjutamine (write miss)
  - Kirjutatakse info põhimällu ilma vahemälu vahenduseta (write-through)
  - Loetakse esmalt kogu plokk vahemällu ja siis muudetakse vastav sõna
vahemälus (write-back)


Info paigutus vahemalus

Otsene paigutus (direct mapping) iga pohimalu ploki puhul teada, kus asub
Assotsiatiivne paigutus (Assiciative mapping) - kogu info voib paigutada kogu vahemalu ulatuses (pmst tuleb kogu vahemalu labi vaadata)
Assotsiatiivse ryhmana paigutus (set-associative mapping)

N1:
4096 plokist koosneb pohimalu
128 plokki vahemalu
ploki suurus 16 sona (ehk 2 baiti)
seega pohimalu suurus = 16 * 4096 sona 
vahemalus 128 * 16 sona


Otsene paigutus

|Plokk 0|plokk 1| Plokk 2|...|Plokk 4095| (pohimalu)

|Plokk 0|Plokk 1|...|Plokk 127| vahmealu (igal plokil silt)

Malu plokk j pannakse C plokist koosnevas vahemalus plokki (j mod C) (siin C=128)
0 mod 128 = 0
128 mod 128 = 0
molemad pointivad vahemalus plokile 0
1 ja 129 pointivad plokile 1 jne

malu aadress jagatakse 3-ks osaks

|b15-b11 (silt)|b10-b4 (plokk)|b3-b0 (sona)|

sona-vali maarab sona asukoha plokis
ploki-vali maarab ploki koha vahemalus
sildi-vali (tag field) maarab milline pohimalust paiknevatest plokkidest vahemallu kirjutati

plokk 0 = 0000
plokk 1 = 0001
plokk 127 = 00000(sildi vali)111...
plokk 128 = 00001(sildivali)111...

Asjakohasuse bit (valid bit) - See bitt ütleb, kas andmed vahemälus on asjakohased
• Arvuti sisselülitamisel kõik need bitid väärtusega 0
• Info laekumisel seatakse selle biti väärtuseks 1
• Kui põhimälu uuendatakse vahemälust mööda minnes, tuleb kontrollida
selle ploki olemasolu/puudumist vahemälus
– kui see plokk vahemälus, siis seatakse selle biti väärtuseks 0
– stale-data
• Samalaadsed mured DMA ülekannete puhul mälust kõvakettale
– Siin on võimalik olukord, kus põhimälus ei ole adekvaatne info (write-back
protocol)
– Üks võimalus andmed jõuga kaasajastada ja alles siis DMA ülekanne teha
– Seda probleemi nimetatakse vahemälu koherentsuse küsimuseks
