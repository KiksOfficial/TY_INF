Binary
----------------- 

sama loogika

N: 101 101 = 1 x 2**5; 0 x 2**4; 1 x 2**3; 1 x 2**2; 0 x 2**1; 1 x 2**0; = 45
vahemik = 0 .. 2**n-1

komade puhul negatiivsed astmed
2**n ja n < 0

EHK NR = digit x x**y 
x = base 
y = num of digits 

TEISENDAMINE: base 10 -> base 2 / base 16

TÄISARV (Jagamise meetod):
1. Jaga arv alusega (2 või 16).
2. Kirjuta täisarvuline JÄÄK üles.
   - Base 2 puhul: jääk on 0 või 1.
   - Base 16 puhul: jääk 10-15 asenda tähtedega A-F.
3. Korda jagatise täisosaga, kuni täisosa on 0.
4. Tulemus: Kirjuta jäägid ALT ÜLES (esimene jääk läheb Paremale, viimane Vasakule).

MURDOSA (Korrutamise meetod):
1. Korruta murdosa alusega (2 või 16).
2. Tulemuse TÄISOSA kirjutad komakoha taha (vasakult paremale).
   - Base 16 puhul: täisosa 10-15 asenda tähtedega A-F.
3. Võta järgmisesse sammu edasi AINULT uus murdosa (lahuta tulemusest täisosa).
4. Korda, kuni murdosa on 0 või saavutad nõutud täpsuse.
