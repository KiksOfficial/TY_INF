Lahendus on IO liides
IO a tyypi vaartus - masin arvutab a tyypi vaartuse
pure : a -> IO a masin tagastab argumendi vaartuse
(>>=) : IO a -> (a -> IO b) -> IO b masin kaivitab esimese argumendi ja rakendab tulemust teisele

lisaks baasfuncid nagu putStrLn : Stinrg -> IO () ja getLine : IO String (votab kasutaja sisendi)

Do syntaks algab do-ga, millele jarnevad jarjest toodeldavad laused

do seob kokku IO-avaldised, kuid ei saa vaadata konstruktsioonide sisse: See tähendab, et üheainsa avaldise jaoks pole eraldi do-plokki vaja.
Näiteks: main = putStrLn "Hello World!"

Hargnemise puhul võib olla vaja kasutada mitut do-d: Kui tingimuslause (if-then-else) harus on vaja sooritada mitu tegevust järjest, tuleb kasutada täiendavat do-plokki.

main : IO ()
main = do
    putStrLn "Kirjuta midagi!"
    xs <- getLine
    if (xs=="")
        then putStr "Sõnakuulmatu!"
        else do
            putStrLn "Tänan!"
            putStrLn ("Kirjutasid: " ++ xs)
