==================================================
 TÜÜPISÜSTEEMI ALUSED (LIHTSALT TÜÜBITUD LAMBDA-ARVUTUS)
==================================================
Tüübisüsteem koosneb 3 peamisest komponendist:
  1. Tüüpide hulk
  2. Programmide/termide hulk
  3. Tüüpimisreeglid

--------------------------------------------------
1. LIHTSAD TÜÜBID (LAMBDA-TÜÜBID)
--------------------------------------------------
Süntaks:
  r ::= b            (baastüübid)
      | r1 -> r2     (funktsiooni tüübid)

Tüübikonstruktor on parem-assotsiatiivne:

  r1 -> r2 -> r3  ===  r1 -> (r2 -> r3)

--------------------------------------------------
2. TÜÜPIDEGA LAMBDA-AVALDISTE STIILID
--------------------------------------------------
Tüüpidega lambda-avaldiste esitamiseks on kaks peamist stiili:

* Church'i stiil:
  - Funktsiooni parameetrite tüübid esitatakse ilmutatult lambda-termis (lambda x : tau. e).
  - Näide: lambda x : Int. add x x : Int -> Int.
  - Igal termil on unikaalne tüüp.

* Curry stiil:
  - Termid on tavalised (ilma tüüpideta) ja kasutatakse tüübikorrektsuse predikaati (tüübituletus).
  - Näide: lambda x. add x x : Int -> Int.
  - Termidel võib olla mitu tüüpi (nt lambda x. x : Int -> Int, aga ka lambda x. x : Bool -> Bool).

* Märkus: Antud kursusel kasutatakse põhiliselt Church'i stiili.
* Subduktsioon, reduktsioon jne on defineeritud analoogselt puhta lambda arvutusega, 
  ignoreerides tüübiannotatsioone.


--------------------------------------------------
3. TERMI SÜNTAKS
--------------------------------------------------

e ::= x                  (muutuja)
    | c                  (konstant)
    | e1 e2              (applikatsioon ehk rakendus)
    | lambda x : T. e    (abstraktsioon)

Samad süntaksilised konventsioonid nagu puhtas lambda arvutuses.


--------------------------------------------------
4. TÜÜPIMISRELATSIOON JA KONTEKST
--------------------------------------------------

Baasrelatsioon on kujul: 
  Gamma |- e : tau  (termil e on tüüp tau kontekstis Gamma)

* Kontekst Gamma on muutujast ja tüübist paaride hulk: 
  Gamma = {x_1 : tau_1, ..., x_n : tau_n}
* Korrektses tüüpimisrelatsioonis peab kehtima: 
  FV(e) <= {x_1, ..., x_n}
* Lisatingimus: x not in dom(Gamma) (muutuja ei tohi kontekstis mitu korda esineda).


--------------------------------------------------
5. TÜÜPIMISREEGLID
--------------------------------------------------
Reegli struktuur: kriipsu peal on eeldused ja kriipsu all järeldus.

1. Konstant (cons) - kui c on tau tüüpi konstant:

       ------------------
       Gamma |- c : tau

2. Muutuja (var) - kui muutuja x on kontekstis tüüpi tau:

       ----------------------
       Gamma, x : tau |- x : tau

3. Abstraktsioon (abs) - lambda-termi tüüp:

       Gamma, x : sigma |- e : tau
       ------------------------------------
       Gamma |- lambda x : sigma . e : sigma -> tau

   (Selgitus: termi tüüp saab olla sigma -> tau eeldusel, et kui lisame 
   konteksti muutuja x tüübiga sigma, siis lambda keha e tüüp on tau.)

4. Applikatsioon (app) - funktsiooni rakendamine:

       Gamma |- e1 : sigma -> tau     Gamma |- e2 : sigma
       ---------------------------------------------------
       Gamma |- e1 e2 : tau

   (Selgitus: e1 peab olema funktsiooni tüüpi sigma -> tau, e2 peab olema 
   tüüpi sigma ning tulemuseks on tüüp tau.)


--------------------------------------------------
6. PROGRAMM (KINNINE TERM)
--------------------------------------------------

Programm e on tüüpi tau, kui tal on see tüüp tühjas kontekstis:
  |- e : tau

Naited:
{x:t, y:sigma} |- x : [t (c)]
{x:t} |- lambda y:sigma.x : [sigma -> t(c)(b)]
-----------------------------------------------
|- lambda x: t, y:sigma.x : [t->sigma->t (b)(a)]

Konstantidega tüüpimispuu
========================
                                                                                f : Int -> Int^\alpha -> f : Int^\delta -> Int^\gamma         f : Int -> Int^\alpha -> 5 : Int^\delta
--------------------------------------------------------- con                 ------------------------------------------------------------------------------------------------------------------ app
f : Int -> Int^\alpha \vdash add : Int^\gamma -> Int -> Int^\beta                   f : Int -> Int^\alpha \vdash f 5 : Int^\gamma
------------------------------------------------------------------------------------------------------------------ app
                    f : Int -> Int^\alpha \vdash add (f 5) : Int -> Int^\beta
------------------------------------------------------------------------------------------------------------------ abs
           \vdash \lambda f : Int -> Int^\alpha . add (f 5) : (Int -> Int^\alpha) -> Int -> Int^\beta \sigma

* Tüübiohutus:
  Korrektselt tüübitud programmid "ei lähe valesti".
* Hind:
  * Mõned mõistlikud programmid hüljatakse.
* Koosneb kahest osast:
  * Progress: Korrektselt tüübitud ei ole tupikus (ta on kas väärtus või saab teha ühe väärtustusreeglitele vastava sammu).
  * Säilitamine: Kui korrektselt tüübitud term teeb ühe sammu, siis ka resultaat on korrektselt tüübitud.

* Tüüpide unikaalsus:
  Kui \Gamma \vdash e : \tau_1 ja \Gamma \vdash e : \tau_2, siis \tau_1 = \tau_2.

* NB! Tüüpide unikaalsus ei kehti mitmete rikkamate keelte korral.

* Tüüpide säilitamine (subjekt-reduktsioon):
  Kui \Gamma \vdash e : \tau ja e \twoheadrightarrow_\beta e', siis \Gamma \vdash e' : \tau.
