  tyypide hulk
  programmide/termide hulk
  tyypimisreeglid

lihtsad tyybid ehk lambda -> tyybid
nende syntaks r ::= b (baastyybid)
                | r1 -> r2 (func tyybid)

tyybikonstruktor on parem assotsiativne

r1 -> r2 -> r3 = r1 -> (r2 -> r3)

* Tüüpidega \lambda-avaldiste esitamiseks on kaks peamist stiili.

* Church'i stiil: funktsiooni parameetrite tüübid esitatakse ilmutatult \lambda-termis \lambda x : \tau. e.
  * Näiteks: \lambda x : Int. add x x : Int -> Int.
  * Igal termil on unikaalne tüüp.

* Curry stiil: termid on tavalised (s.o. ilma tüüpideta) ja kasutatakse tüübikorrektsuse predikaati (tüübituletus).
  * Näide: \lambda x. add x x : Int -> Int.
  * Termidel on palju tüüpe (näit. \lambda x. x : Int -> Int, kuid ka \lambda x. x : Bool -> Bool).

* Meie kasutame põhiliselt esimest stiili.

Termi syntaks

e ::= x (muutuja)
    | c (konstant)
    | e1 e2 (applikatsioon)
    | \lambda x: T. e (abstraktsioon)

samad syntaksilised konventsioonid nagu puhtas lambda arvutuses

subduktsioon, reduktsioon jmt. on defineeritud analoogselt puhta lambda arvutusega, ignoreerides tyybiannotatsioone


* Baasrelatsioon on kujul \Gamma \vdash e : \tau   (term e on tüüpi \tau kontekstis \Gamma)

  * \Gamma on muutujast ja tüübist paaride hulk {x_1 : \tau_1, ..., x_n : \tau_n}.

  * Korrektses tüüpimisrelatsioonis peab olema FV(e) \subseteq {x_1, ..., x_n}.

* Lihtsalt tüübitud \lambda-arvutuse tüüpimisreeglid:

  c on \tau tüüpi konstant
  ------------------------ |-ui nocs c on tyypi tau ss c ongi tyypi tau)
      \Gamma \vdash c : \tau

  \Gamma, x : \sigma \vdash e : \tau
  ------------------------------------ abs (kui termix on lambda x: sigma. e ss selle tyyp saab olla aind sigma -> tau, aga ainult ss kui x: sigma lisame konteksti, siis lambda keha tyyp tleb tau)
  \Gamma \vdash \lambda x : \sigma. e : \sigma \to \tau


  ----------------------- var
  \Gamma, x : \tau \vdash x : \tau (kontekstis on x tyyp tau ss x tyyp ongi tau)


  \Gamma |- e_1 : \sigma -> \tau    \Gamma |- e_2 : \sigma
  ----------------------------------------------------------------- app
  \Gamma |- e_1 e_2 : \tau

(app => kui termile e1 on rakendatud e2, ss e1 peab olema func type sigma -> tau ss e2 tyyp peab olema sigma, mis sinna argumendiks sobib ja tulemus peab olema rakenduse tulemus)


  kus x \notin dom(\Gamma).
  (gammas ei tohi muutuja mitu korda esineda)

Kriipsu all jareldus ja kriipsu peal eeldused

* Programm (s.o. kinnine term) e on tüüpi \tau, kui tal on see tüüp tühjas kontekstis \vdash e : \tau.

Naited:

{x:t, y:sigma} |- x : [t (c)]
{x:t} |- lambda y:sigma.x : [sigma -> t(c)(b)]
-----------------------------------------------
|- lambda x: t, y:sigma.x : [t->sigma->t (b)(a)]



Konstantidega tüüpimispuu

========================
                                                                                f : Int -> Int^\alpha \vdash f : Int^\delta -> Int^\gamma         f : Int -> Int^\alpha \vdash 5 : Int^\delta
--------------------------------------------------------- con                 ------------------------------------------------------------------------------------------------------------------ app
f : Int -> Int^\alpha \vdash add : Int^\gamma -> Int -> Int^\beta                   f : Int -> Int^\alpha \vdash f 5 : Int^\gamma
------------------------------------------------------------------------------------------------------------------ app
                    f : Int -> Int^\alpha \vdash add (f 5) : Int -> Int^\beta
------------------------------------------------------------------------------------------------------------------ abs
           \vdash \lambda f : Int -> Int^\alpha . add (f 5) : (Int -> Int^\alpha) -> Int -> Int^\beta \sigma

* Tüübiohutus:
  Korrektselt tüübitud programmid "ei lähe valesti".

* Hind:
  * Mõned mõistlikud programmid hüljatakse.

* Koosneb kahest osast:
  * Progress: Korrektselt tüübitud ei ole tupikus (ta on kas väärtus või saab teha ühe väärtustusreeglitele vastava sammu).
  * Säilitamine: Kui korrektselt tüübitud term teeb ühe sammu, siis ka resultaat on korrektselt tüübitud.

* Tüüpide unikaalsus:
  Kui \Gamma \vdash e : \tau_1 ja \Gamma \vdash e : \tau_2, siis \tau_1 = \tau_2.

* NB! Tüüpide unikaalsus ei kehti mitmete rikkamate keelte korral.

* Tüüpide säilitamine (subjekt-reduktsioon):
  Kui \Gamma \vdash e : \tau ja e \twoheadrightarrow_\beta e', siis \Gamma \vdash e' : \tau.
