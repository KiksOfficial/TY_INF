TID - Thread ID

struct job { int in, out; };

void *worker(void *arg) {
  struct job *j = arg;
  j->out = j->in * j->in;
  return NULL;
}

struct job j[2] = {{2, 0}, {3, 0}};
pthread_t t[2];

for (int i = 0; i < 2; i++)
  pthread_create(&t[i], NULL,worker, &j[i]);

for (int i = 0; i < 2; i++)
  pthread_join(t[i], NULL);


• create: uus lõim alustab
funktsioonist worker.
• join: oota selle lõime lõppu.
• Argumendi objekt peab elama
töö lõpuni.
